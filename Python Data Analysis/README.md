# 👨🏻‍💻 Python Data Analysis

A practical Python data-analysis project using **NumPy, Pandas, and Matplotlib** to
analyze employee and sales data.  
The project covers salary, experience, department, monthly sales, and product
performance through data manipulation and visualization.

---

## 🔍 Analysis

### 🐼 Employee Analysis

The employee dataset was analyzed to examine:

- Salary levels and distribution
- Salary differences across departments
- Employee distribution by department
- Experience versus salary
- Employees meeting salary-based conditions

### 📈 Sales Analysis

Monthly sales data from January to June was analyzed to examine:

- Monthly sales performance
- Department-level sales differences
- Product-level sales performance
- Highest monthly sales
- Cumulative sales progression

### 📊 Visualization

Matplotlib was used to present the analysis through:

- Monthly sales trends
- Department salary comparisons
- Salary distribution
- Department composition
- Experience versus salary
- Product sales comparisons
- Cumulative sales trends
