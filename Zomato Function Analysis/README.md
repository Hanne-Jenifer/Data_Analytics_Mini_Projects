# 🔢 Excel Numerical Functions

This assignment focuses on applying numerical functions in Microsoft Excel to a structured restaurant dataset.  
The workbook contains function-specific worksheets where Excel formulas are used to solve numerical questions based on the provided data.

## 🎯 Project Focus

The assignment covers practical application of Excel numerical functions, including:

- Selecting the appropriate function for a given numerical problem.
- Applying formulas to structured dataset fields.
- Working with function-specific worksheets.
- Interpreting calculated results from Excel formulas.

## 📂 Dataset

The workbook contains a structured **restaurant dataset** with fields covering restaurant identification, location, and geographic information.

| Field | Description |
|---|---|
| Restaurant ID | Unique identifier for each restaurant |
| Restaurant Name | Name of the restaurant |
| Country Code | Country code associated with the restaurant |
| City | City where the restaurant is located |
| Address | Restaurant address |
| Locality | Restaurant locality |
| Locality Verbose | Detailed locality information |
| Longitude | Geographic longitude |
| Latitude | Geographic latitude |

## 🔢 Functions Practiced

The workbook contains dedicated worksheets for numerical functions such as:

- **SUM** — numerical aggregation
- **AVERAGE** — calculating mean values
- **SUMPRODUCT** — performing calculations across multiple ranges
- **Other numerical functions** included in the exercise workbook

Each function worksheet contains specific questions requiring formulas to be applied to the provided dataset.

## 📊 Workbook Structure

- **Dataset Tab** — source restaurant data.
- **Function Tabs** — individual worksheets for practicing numerical functions.
- **Task Cells** — designated cells where formulas are entered to solve the assigned questions.

## 🛠️ Tools & Technologies

- **Microsoft Excel**
- **Excel Formulas**
- **Numerical Functions**
- **Structured Data**

## 🏁 Outcome

This assignment demonstrates foundational Excel proficiency through hands-on application of numerical functions to a structured restaurant dataset.

It provides practical experience in formula selection, numerical calculation, and working with structured data in Excel.
