## 🛠️ Tools & Techniques

Depending on the project, the repository includes work using:

- **Microsoft Excel** — data analysis, formulas, functions, and dashboards
- **Microsoft Power BI** — data modeling, measures, analysis, and interactive dashboards
- **SQL** — querying, aggregation, subqueries, CTEs, window functions, and analysis
- **Python** — data manipulation, numerical analysis, and visualization

The specific tools and techniques used in each project are documented within its respective project folder.

---

## 🔄 Analytics Workflow

Projects may involve different stages depending on their scope:

**Data → Cleaning → Exploration → Analysis → Visualization → Insights**

Not every project follows every stage; each assignment is documented according to the work actually performed.
